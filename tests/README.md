# 🔎 Testes unitários

> Este repositório reúne meus projetos de estudo com foco em praticar testes automatizados, aplicados sobre operações CRUD: `Create` (Criar/cadastrar), `Read` (Ler/consultar), `Update` (Alterar/Atualizar) e `Delete` (Excluir/Deletar).

## 📚 Aprendizados

Durante o desenvolvimento dos projetos também são praticados conceitos como:

* Arquitetura em camadas (controller, service, repository e model)
* Padrão DTO (Data Transfer Object) com Java Records
* Persistência com Spring Data JPA e PostgreSQL
* Tratamento centralizado de exceções
* Testes de integração com Postman
* Padronização de respostas HTTP
* Versionamento e histórico organizado com Git
